# Curriculum — Atlas of the Build Loop (reconstruction)

**Pack title:** Atlas of the Build Loop  
**Edition:** Field atlas (not a map). Sixteen lessons in four arc-packs.  
**Audience:** Mixed prior knowledge. Educational field guide — not a PMI, Scrum.org, or SAFe credential.  
**Spine policy:** The 7-unit syllabus seed is kept as the *subject*. Each named unit is now taught at pack depth: decision rules, facilitation scripts, primary citations, failure catalogs, and a continuing case.

## Why this reconstruction

The first edition (7 lessons) was a speaking-and-decision primer. An atlas stops resembling a map when each arc can stand as its own study pack: you can spend a week inside Arc A and leave able to *run* the loop, not only name it.

## Four arc-packs

| Arc | Lessons | Job of the mini-pack |
| --- | --- | --- |
| A — The door | L01–L04 | Name the work; pick and run a loop |
| B — Methods and intent | L05–L08 | Choose a coat; write intent others can execute |
| C — Tools | L09–L12 | Generate options; run the smallest honest test |
| D — Guardrails and ship | L13–L16 | Critique; decide; switch into delivery with ops |
