# Lesson write spec (reconstruction)

Write markdown only under `02_lessons/{STEM}.md`. Do not invent studies or fake URLs. Educational only.

## Required H2 skeleton (in this order)

1. `# Title`
2. `## Learning Objectives` — 5–7 bullets, observable
3. `## Prerequisites`
4. `## Lesson Content` — **at least 8 H3 sections**. Each H3 has 2+ real paragraphs (not bullet-only). Include:
   - Mechanism / what the move is FOR
   - Decision rule
   - Failure catalog
   - **Facilitation script** (minute-by-minute or timed agenda) in at least one H3
   - At least one HTML `<figure class="fig">` with SVG or structured HTML (no text-in-bitmap)
5. `## Worked example(s)` — continue the **contractor onboarding** case (tax packet / findability / pre-fill / leadership demo). Numbered steps, result.
6. `## Key Terms` — markdown table, **≥10 rows**
7. `## Misconception inventory` — table, **≥8 rows**
8. `## Summary` — ≥6 bullets
9. `## Practice` — Retrieval (≥5), Near transfer, Far transfer
10. `## Spaced retrieval notes` — Day 0, 2, 7, 21
11. `## Difficulty tiers` — Novice / Working / Expert
12. `## Domain scaffolds`
13. `## Learn more` — only real URLs from PRIMARY_SOURCES.md plus the three already used (agilemanifesto, scrumguides, designcouncil). Optional NN/g and HBR Cynefin.

**Length:** Lesson Content + Worked example ≥ **2,400 words**.

**Voice:** Field guide. Coats not identities. No SAFe. No cardio leftovers.

**Links in markdown:** `[label](https://...)` only.
